# Royal Princess 2026 Travel Website

這是一個純 HTML / CSS / JavaScript 的靜態旅遊網站，不需要 Node.js、React 或資料庫。

## 使用方式

1. 把 `index.html` 上傳到 GitHub Repository 根目錄。
2. GitHub Repository → Settings → Pages。
3. Source 選 `Deploy from a branch`。
4. Branch 選 `main`，Folder 選 `/ (root)`。
5. 儲存後等待 GitHub Pages 發布。

發布網址通常會是：

`https://你的GitHub帳號.github.io/Repository名稱/`

## 功能

- 10/2–10/16 每日行程
- 郵輪硬性回程／回船時間提醒
- Google Maps 一鍵導航
- 行李與證件 Checklist（localStorage）
- 多幣別簡易記帳（localStorage）
- 手機響應式版面

## 注意

Checklist 與記帳資料只存在目前瀏覽器／裝置，不會跨裝置同步。
實際 All Aboard 時間請以 Princess App／船上公告為準。
